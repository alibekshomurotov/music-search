# 🎵 Music Search App

Bu React yordamida yaratilgan zamonaviy Music Search loyihasi.
Foydalanuvchilar qo‘shiq yoki artist nomini qidirib musiqalar haqida ma’lumot olishlari mumkin.

## 🌐 Live Demo

🔗 [https://your-music-search-link.com](https://alibekshomurotov.github.io/music-search/)

---

## 📌 Loyiha Haqida

Ushbu loyiha foydalanuvchilarga:

* Musiqa qidirish
* Artistlarni topish
* Qo‘shiq ma’lumotlarini ko‘rish
* Zamonaviy interfeys orqali qulay foydalanish imkonini beradi.

---
